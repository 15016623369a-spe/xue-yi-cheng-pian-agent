# 网上找片头

在任意制作步骤点击顶部「⌕ 查找片头」，或在「学习与方向 → 本期片头」打开同一入口。制作动态中的片头任务也有「查看候选 / 调整片头」。候选与条件会保存，重新打开项目仍可查看。此入口只检索网上视频，正文事件的本地素材匹配为独立功能。

## 操作

1. 填人物、关键词或想找的一句原话，至少一项。可补充情绪，选择 B站／抖音，填写期望时长。
2. 点击「搜索并自动接入片头」：最多尝试排名前两条具体视频；填写原话时先用本机转写定位，否则截取原视频开头。成功后才显示「已接入」。也可点击「只查候选」，只查看链接和匹配理由。
3. 自动未接入时显示「片头未接入，待处理」及具体原因。原话至少3个有效字符；唯一匹配可定位，重复出现则列出每处时间点，点击「接入第 N 处」选择。
4. 候选均有原视频链接与平台搜索链接。也可填写原视频起点、终点并关闭自动定位，点击「用作本期片头」；「追加为下一段切片」可以组成多切片开头。
5. 成功后在「学习与方向 → 本期片头」播放带原声的预览。接入修改会取消旧审阅，需要重新审阅并导出整片。交付页将旧成片明确标为历史版本，不会把旧 MP4 当成新片头已生效的成片。
6. 取消「使用本项目已选择的片头」可临时停用，重新开启保留原选择；「移除本期片头」会清除当前选择。原文件和历史版本保留。

新项目默认直接进入正文；表达方向与系列主题、片头素材独立配置，不会自动加入旧项目的开场说明。历史项目中明确选择的片头仍保留。

人物可填写目标创作者，关键词描述希望查找的场景，再填写目标时长。情绪只用于标题文字匹配；不是看完视频后判断的情绪。原话经 ASR 定位也不等于人工听辨。

## 当前能力与边界

| 项目 | 行为 |
| --- | --- |
| B站 | 读取公开 HTML 搜索页；提取真实具体视频链接 |
| 抖音 | 读取搜索引擎公开收录，可能不全；提供抖音搜索入口 |
| 排序 | 人物及关键词、原话、情绪的标题匹配；无关标题不当作命中 |
| 内容核对 | 用户查看原视频；可选本机 Whisper 对原话唯一匹配定位 |
| 截取 | 单段0.5–30秒；追加后总时长≤60秒；规范到720p/30fps |
| 声音 | 保留原声，正式中间片使用 PCM；预览另编码 AAC |
| 限制 | 平台可能要求登录、验证码，或限制获取；失败不替换片头 |
| 用量 | 搜索不调用文字模型；定位使用本机模型，需要已配置的运行环境 |

自动定位最多检查90秒，不会为一条数小时直播下载、转写全部内容。期望长度不是原视频总时长。视频短于预期时，以实际截取长度记录。当前没有视觉语义理解、自动识别人脸、自动判断爆款或完整平台作品爬取。

## 实现与数据

- `video_agent/openings.py`：搜索、解析、排序、可控区间获取、ASR定位、音画准备与登记。
- `web/opening.js`：独立检索弹窗、候选卡片、剪点及替换／追加入口。
- `POST /api/projects/{id}/openings`：`mode: search | search_apply | import`，当前修订号与结构化条件；返回后台任务。
- `GET /api/projects/{id}/openings`：最近一次真实检索报告。
- `.web/opening-search/{id}/`：检索及下载／媒体缓存；`.web/opening-asr/`：转写缓存；均不进入 Git。
- 原片头、原文件和项目历史保留。正式登记在项目 `assets/openings/`，来源和剪点保存在 `config.opening.segments`。

检索缓存10分钟；媒体缓存按输入摘要、实现与工具身份建立，命中前检查产物哈希。错误结果不伪装成成功。只接受抖音和 B站的具体 HTTPS 视频页；不执行候选标题或网页中的指令，不读取浏览器登录信息。
