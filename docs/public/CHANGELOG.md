## 2026-10-31 · 片头检索、接入与版本管理

### 新增

| 功能 | 使用方式与行为 |
| --- | --- |
| 常驻查找入口 | 顶部「⌕ 查找片头」、第一步「本期片头」、制作动态中的「查看候选 / 调整片头」打开同一界面 |
| 条件检索 | 按人物、关键词、原话、情绪、平台和目标时长，获取具体视频候选及匹配理由 |
| 自动尝试接入 | 「搜索并自动接入片头」最多尝试前两条；填写原话时先定位，否则试用视频开头 |
| 候选核对与选择 | 保留「只查候选」、原视频链接、平台搜索入口、手动起止点和重复原话的多个时间点 |
| 原声片头管理 | 截取替换、追加为下一段、原声预览、停用后恢复及移除；正式媒体与浏览器预览分别准备 |
| 检索结果持久化 | 条件、候选和接入状态保存在项目中，重新打开可继续查看和处理 |

### 修复

- 新项目默认无片头；表达风格、系列主题与片头独立，不再自动继承旧项目的开场说明。
- 启用片头但未选择素材时明确提示，不静默使用其他默认素材。
- 接受至少三个有效字符的原话；匹配多处时列出时间点，无法确定时保持待处理，不伪报成功。
- 分开显示「找到候选」「已接入」「未接入待处理」与「已导出」；替换片头后需要审阅并重新导出成片。
- 交付页按项目修订展示当前成片，旧版本单独标识；修复首次打开交付页时历史结果未及时显示的问题。
- 媒体未准备完成或项目已被编辑时，不覆盖当前片头及期间的手动修改。

### 范围与限制

候选根据公开标题和文字条件匹配，不等于视觉理解或完整视听分析。B站使用公开搜索页，抖音依赖搜索引擎公开收录，可能缺失或不可获取。原话定位使用本机 Whisper，扫描起点后最多90秒。单段0.5–30秒，串联总长不超过60秒。搜索不消费文字模型额度；媒体获取和本机定位需要相应工具。登录、验证码和其他平台限制不会被绕过。

详见 [网上找片头](OPENINGS.md)。

## 2026-10-30 · 自动纠错、失败恢复与用量追踪

### 新增与改进

- **事件触发句修复**：存在充分且唯一的逐字重合时，使用本镜口播片段修复触发句，再重新校验；不改写口播或知识依据。
- **分步检查点**：提取成功独立保存，后续改编失败时可复用；缓存损坏时重新检查并恢复有效步骤。
- **临时故障重试**：模型连接和部分临时工具错误最多恢复一次；永久配置、访问条件或内容问题给出处理建议。
- **总请求约束**：一次知识提取与分镜改编共用四次 HTTP 请求上限，包含连接重试及内容修正。
- **损坏缓存恢复**：阶段产物与素材匹配缓存检查摘要；损坏结果重建，保留已有有效素材选择。
- **执行记录**：制作动态展示修复前后、自动恢复次数、复用步骤、已知请求用量与失败建议。无法取得的用量标记未知。

自动处理以可验证规则为边界，不会自动提高预算、切换付费服务或放宽最终技术检查。知识正确性、素材适用性和声音表达仍需要审阅。详见 [自动纠错与失败恢复](AUTO_RECOVERY.md)。
