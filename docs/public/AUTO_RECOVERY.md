# 自动纠错与失败恢复

[返回 README](../../README.md)

工作流采用“检查 → 能确定则修复 → 重新检查 → 有限重试 → 保留结果并说明原因”。自动修复只处理可验证的技术问题，不把缺失的素材、事实或授权补成虚构结果。

## 各步骤如何处理

| 步骤 | 自动处理 | 仍需人工处理的情况 |
| --- | --- | --- |
| MD 导入与知识提取 | 原文行号回填逐字引文；旧引文仅在全文唯一完全匹配时重定位；模型格式或结构不合格可修正一次 | 原文不足、结论与引文含义不符、事实本身有误 |
| 讲稿与分镜 | 检查知识覆盖、模板和事件；生成的触发句与本镜口播有足够长且唯一的逐字重合时取原句片段，再重新校验；其余结构错误可请求模型修正一次 | 没有可靠重合、重复句无法唯一定位、需要改写教学内容 |
| 模型连接 | 对临时超时、连接中断及 HTTP 408/425/429/500/502/503/504 最多重试一次 | 密钥、额度、模型配置、证书等问题；不关闭 TLS 检查 |
| 素材匹配 | 保留已选素材；弱匹配留空；下载失败记录原因；损坏的匹配缓存重新构建，模型连接沿用有限重试 | 图像是否真的适合、缺少访问条件；不会用无关素材强行填满 |
| 网上片头 | 下载和转写使用摘要缓存；临时工具故障可恢复一次；唯一原话自动定位，重复原话列出时间点 | 验证码、登录、原话缺失或剪点含糊时保持待处理，保留原片头 |
| 配音与字幕 | 本地短句生成至多三次，检查漏读、重复、数字和末句覆盖；只使用通过检查的音频与转写 | 多次尝试仍不通过，需调整术语读法或参考声音；音色和语气需试听 |
| 画面、封面与总装 | 产物哈希检查、坏缓存重建；浏览器关闭或制作超时等临时故障最多恢复一次，复用已完成阶段 | 缺文件、非法参数或持续失败；不放宽最终技术检查 |

恢复不会覆盖期间的手动修改。版本冲突时保留生成结果，供核对后合并。后台进程被直接终止属于中断，需要重新开始任务；不会自动无限拉起进程。

## 次数与用量

- 一次知识提取与分镜改编共用 **4 次 HTTP 请求上限**，包括连接重试和内容修正；两阶段各最多一次内容修正。
- 素材匹配最多两个模型选择步骤，每个连接最多两次 HTTP 尝试；不整项反复调用模型。
- 提取成功即保存独立检查点。改编失败后重试，输入和配置未变则复用知识；完整缓存损坏时，重新校验并恢复有效的步骤缓存。
- 缓存命中先验证输入摘要、产物哈希及当前规则。失败请求返回了用量就记录；无法取得用量则显示未知，不按免费计算。
- 不自动提高输出预算、不切换付费服务、不改动事实、不以空白结果冒充成功。

## 在工作台查看

任务卡显示自动恢复次数、复用步骤、请求用量和失败后的处理建议。发生触发句修复时，对应事件显示原写法和修复后的逐字片段；手动编辑触发句后该标记清除。旧任务保留原有历史状态。

出处和技术检查通过仅说明满足这些规则，不能代替知识审阅或完整视听审核。

## 验证方式

`tests/test_recovery.py` 使用本地 HTTP 服务、受控错误和临时工作区，验证唯一锚点修复、失败步骤复用、缓存损坏恢复、请求总次数、临时故障恢复和永久错误停止。它不调用付费模型，也不把模拟浏览器故障当作真实渲染崩溃的验证。
