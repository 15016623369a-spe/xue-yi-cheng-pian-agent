# 系列、标题与素材清理

[返回 README](../../README.md)

## 系列名与每期标题

第一步的「系列与本期标题」分开管理栏目定位和单期选题：

1. 填写系列名称，点击「设为新项目默认系列」，以后新建项目继承该名称；已有项目保持自己的设置。
2. 导入笔记并生成分镜。改编时模型会为本期起名；也可以点击「根据本期内容起标题」单独获取3–5个候选。
3. 有分镜时依据当前口播、知识结论及适用边界；无分镜时依据原始笔记，属于初拟。
4. 选择候选或手动填写，保存后用于项目名称及后续封面与成片。生成候选本身不修改讲稿或自动采用标题。

模型优先返回具体、易懂的短标题，避免机械拼接系列名。数字、统计单位、开放阶段及结论仍需审阅；格式校验不等于事实审核。候选必须不同、长度4–48个字符。格式错误最多修正一次，临时连接故障可有限重试，一次标题任务总计最多3次HTTP请求，已知用量均保留。

内容、系列或模型配置变化会使相应缓存失效；缓存校验通过时无需再请求模型。候选内容已过期时拒绝直接采用。标题保存会增加修订并清除旧审阅；已导出的封面和成片保留为历史文件，需要重新生成才能体现修改。

## 网上素材的水印处理

第一步可开启「网上素材接入时自动识别并处理平台文字水印」。网上片头导入、带来源记录的联网图片登记会尝试处理；单纯搜索到链接不代表已下载或处理成功。

自动流程在本机抽帧，用 macOS Vision 识别角落的小型平台名称或账号文字，再通过 FFmpeg `delogo` 使用周围像素修补。片头先在原始比例下识别和处理，随后统一画面规格，避免补黑边后影响角落定位。最多抽样10帧，处理素材最长120秒。该过程不发送画面给文字模型，也不消耗文字模型额度。

素材旁的「水印处理 / 恢复原件」还支持：

| 操作 | 行为 |
| --- | --- |
| 自动识别并清理 | 只处理符合规则的角落文字；未识别或工具不可用时明确标记待处理 |
| 开始框选 | 视频暂停后在预览上拖动，可选择最多8处，再点击「清理框选区域」 |
| 清空框选 | 清除当前选择，重新标记 |
| 恢复原件 | 恢复保留的处理前素材；重复处理也从原件开始，避免逐次劣化 |

原件、来源记录和清理报告分别保留。正式视频中间文件使用PCM音频，不调整原声语速或音量；浏览器预览单独编码为AAC。处理结果通过解码和时长检查后才能更新素材，并受项目修订冲突保护。修改期间项目发生变化时保留处理结果，不覆盖新编辑。

## 预览与限制

像素修补可能产生模糊或边缘痕迹，不是无损重建。艺术字、居中、大型、移动或短暂水印可能漏检；抽样未识别不能理解为无水印。请预览处理区域，必要时调整框选。动图和视频会重新编码。图片、动图中的复杂透明边缘也需要人工检查。

自动文字识别目前仅支持有系统Swift编译器的macOS；其他平台可使用框选处理。完整视频工具环境和FFmpeg的`delogo`滤镜是前提。不会绕过素材平台的登录、访问或下载限制。源文件的作者、出处和许可元数据不因画面清理而删除。
